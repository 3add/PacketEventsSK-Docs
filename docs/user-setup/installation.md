# Installation

Installing PacketEventsSK is easy, just download the latest version of PacketEventsSK and packetevents (see below) and place them in your plugins folder.

### [PacketEventsSK](https://modrinth.com/plugin/PacketEventsSK) - [PacketEvents](https://modrinth.com/plugin/PacketEvents)

## Additional Dependencies
- Only [Paper](https://papermc.io/downloads/paper) 1.21.10 or later is supported.
- Only [Skript](https://modrinth.com/plugin/skript) 2.15 or later is supported.
- It is suggested that you also install [SkBee](https://modrinth.com/plugin/SkBee) 1.17.2 or later as some features do require it's presence, but it is not required.

Other versions may work but support is not provided for them.
