# Introduction
Welcome to the documentation for PacketEventsSK. PacketEventsSK is an addon that let's you interact with [PacketEvents](https://github.com/retrooper/packetevents) API without the use of reflect.
The use of packets allows users to have full control of their minecraft server and packetevents is the  most modern and efficient way of handling packets in Minecraft.

### Advantages of PacketEvents
- Better performance than most APIs (think ProtocolLib) due to the use of modern techniques and optimizations.
- A complete implementation of the [Minecraft Protocol](https://minecraft.wiki/w/Java_Edition_protocol/) without falling back on Paper, Bukkit or NMS.

### PacketEventsSK's Role
- Conversion between packetevents' types and Skript types.
- Providing access to the packetevents API through Skript syntax.
